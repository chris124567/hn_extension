HN Guideline Collapser

How the extension uses data

When you open a Hacker News discussion, the extension asks classify.stylometry.net for the precomputed scores for that page's public comments. To do this, it sends the page's numeric item ID over HTTPS. The request also exposes your IP address and standard request metadata to the service's Cloudflare CDN.

It does not send comment text, your Hacker News identity, votes, cookies, or browsing activity outside Hacker News item pages. See the privacy policy for details.

Classification is enabled by default so comments collapse immediately. Clear the checkbox below to stop all classifier requests and automatic collapsing.

Collapse thresholds

A comment is collapsed when its classifier score meets a rule's threshold. Lower values collapse more aggressively. Setting a rule to 1.00 disables it. Hover over a rule's name to read the full guideline.
